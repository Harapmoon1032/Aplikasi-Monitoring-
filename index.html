Ekosistem Digital KBM

Fitur Utama

Sistem ini dirancang untuk memotong kerumitan administrasi KBM dan menggantikan jurnal kertas manual dengan ekosistem digital yang serba cepat:

Input Jurnal Kilat (< 1 Menit)

Guru cukup memilih kelas dan mapel, memasukkan materi hari ini, lalu simpan. Tidak ada lagi tumpukan buku jurnal fisik yang rentan hilang.

Presensi Siswa Presisi & Real-Time

Rekam status kehadiran siswa (Hadir, Sakit, Izin, Alpa) yang otomatis terkunci pada sesi mengajar hari itu. Pencegahan double-input menjaga akurasi data tetap 100%.

Smart Dashboard & Live Analytics

Pantau statistik kehadiran siswa per kelas dan tingkat keaktifan mengajar guru secara visual lewat grafik dinamis yang langsung diperbarui otomatis.

One-Click Report Export

Rekapitulasi laporan bulanan hingga semesteran bisa ditarik kapan saja ke format Excel (.xlsx) atau PDF siap cetak lengkap dengan filter per tanggal, kelas, atau mapel.

Log Catatan Kendala KBM

Ruang khusus bagi guru untuk mencatat dinamika kelas (misal: kendala fasilitas atau penanganan siswa), memudahkan koordinasi lanjutan dengan Wali Kelas dan Tim BK.

Master Data Terpusat & Terintegrasi

Pengelolaan data puluhan guru, ribuan siswa, dan rombongan belajar dalam satu basis data yang rapi dan terstruktur.

Lightweight Deployment

Persyaratan Sistem (System Requirements)

Sistem ini didesain sangat ringan (lightweight) sehingga bisa dijalankan di server lokal sekolah (LAN) maupun layanan cloud hosting.

Sisi Server (Minimum)

  • Lingkungan Web: Apache 2.4+ / Nginx 1.18+
  • Bahasa Pemrograman: PHP 8.1+
  • Database Engine: MySQL 8.0+ / MariaDB 10.5+ (Support InnoDB Engine)
  • Sistem Operasi: Linux (Ubuntu Server / Debian) atau Windows Server

Sisi Pengguna (Client)

  • Perangkat: PC Desktop, Laptop, Tablet, atau HP (Android/iOS)
  • Browser: Google Chrome, Mozilla Firefox, Microsoft Edge, atau Safari versi terbaru
  • Jaringan: Terkoneksi ke Wi-Fi/LAN Sekolah atau Internet (Minimal bandwidth 2 Mbps)

Tentang Aplikasi

Sistem Informasi Jurnal Mengajar & Presensi Siswa adalah platform transformasi digital yang diciptakan untuk modernisasi tata kelola akademik sekolah.

Banyak waktu guru terbuang hanya untuk urusan administrasi kertas dan rekapitulasi manual. Aplikasi ini hadir sebagai solusi satu pintu yang memberikan efisiensi bagi guru saat mengajar, akurasi data bagi wali kelas, serta transparansi laporan riil bagi manajemen sekolah. Lebih hemat waktu, bebas kertas (paperless), dan siap mendukung digitalisasi sekolah secara menyeluruh.
